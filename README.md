# WinRansomProtect (Trial Available)

**Offline Anti-Ransomware for Windows 10/11.**

WinRansomProtect watches your files and stops ransomware before it can encrypt them. 32 rules cover the common attack paths — file encryption, malicious scripts, suspicious processes. It runs 100% offline, uses under 5% CPU, and doesn't touch the network.

## ✨ Key Features
- **32 Real-time Protection Rules:** Signature + behavior dual analysis.
- **Instant Response:** Catches malicious commands within 200ms.
- **Process Blocking:** Stops malicious PowerShell/CMD scripts.
- **Quarantine & Restore:** Safe removal with rollback capability.
- **100% Offline:** No cloud, no telemetry, no data collection.
